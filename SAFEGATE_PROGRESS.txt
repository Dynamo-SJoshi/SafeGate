Important learnings
-------------------

1. Git tracks changes locally, GitHub stores them online.
2. Git workflow for this project:
   - make a small change
   - test it
   - commit it
   - push it to GitHub
3. A Python virtual environment (.venv) is a private Python space for SafeGate only.
4. pip installs Python packages.
5. When .venv is active, pip installs packages only for this project.
6. PostgreSQL can be installed on D: while the project lives on C:.
7. The frontend and backend are separate apps and should be run in separate terminals.
8. Next.js is the frontend framework currently being used.
9. FastAPI is the backend framework currently being used.
10. The small "N" badge in the Next.js app during development is normal.

How to start the backend
------------------------

Folder:
   C:\Users\DELL\Downloads\SafeGate

Steps in Command Prompt:

1. Create the virtual environment:
   python -m venv .venv

2. Activate it:
   .venv\Scripts\activate

3. Install backend dependencies:
   pip install -r backend\requirements.txt

4. Start the backend server:
   uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000

5. Test the backend:
   http://127.0.0.1:8000/health

Expected response:
   {"status":"ok","service":"safegate-api"}

How to start the frontend
-------------------------

Folder:
   C:\Users\DELL\Downloads\SafeGate\frontend

Steps in Command Prompt:

1. Install frontend dependencies:
   npm install

2. Start the frontend dev server:
   npm run dev

3. Open the frontend in the browser:
   http://127.0.0.1:3000

How the frontend connects to the backend
---------------------------------------

1. Browser opens the Next.js frontend on port 3000.
2. The frontend calls its own route:
   /api/health
3. That route calls the FastAPI backend:
   http://127.0.0.1:8000/health
4. The frontend shows backend status as online when the backend responds correctly.

Security / design decisions
---------------------------

1. Treat all uploads as hostile.
2. Prefer static analysis before dynamic execution.
3. Do not run unknown files on the host.
4. Use temporary data and cleanup later.
5. Keep the MVP simple before adding sandbox execution and AI summaries.
