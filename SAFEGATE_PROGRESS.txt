How to run PostgreSQL commands:
1. Open Command Prompt.
2. Connect to PostgreSQL:
   - `psql -U postgres -d postgres`
3. Enter the password when prompted. The password input will not be shown on screen, which is normal.
4. Useful commands inside `psql`:
   - `\dt`
   - `SELECT upload_id, original_filename, size_bytes, match_status, created_at FROM uploads ORDER BY created_at DESC LIMIT 5;`
   - `\q`
5. Exit `psql` with:
   - `\q`

Notes:
- `\dt` lists tables in the connected database.
- The `SELECT` query shows recent SafeGate upload records.
- `\q` quits the PostgreSQL shell.
